# Contributing

Yogurt doesn't accept pull requests yet. Issues are welcome: bug reports, and feature requests that describe the problem you want solved.

Report security problems privately, as [SECURITY.md](SECURITY.md) describes, not in an issue.

## Building

You need Go 1.25, Node and pnpm. `make build` produces `bin/yogurt` with the web interface built in. `make check` runs every check and test.
